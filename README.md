## FAQ

### What is XCutors?

XCutors is a Windows desktop application that bundles several popular Roblox script executors (Volt, Synapse Z, Potassium, Wave) along with a universal loader called xcutorsLoader, allowing users to run custom Lua scripts inside Roblox games.

### Is XCutors free to use?

Yes, XCutors itself is free and open-source. However, some individual executors bundled in the collection may require their own license or subscription depending on the developer.

### Which executors are included in the package?

The current package includes Volt, Synapse Z, Potassium, Wave, and the universal xcutorsLoader. Support for additional executors may be added in future releases.

### What operating system is required?

XCutors is designed exclusively for Windows desktop. Windows 10 and Windows 11 are fully supported. Administrator privileges are required for injection.

### Do I need to install each executor separately?

No. The xcutorsLoader handles all executor management. Simply select an executor from the dashboard and it will be set up automatically on first use.

### Why does my anticomponent flag the application?

Some anticomponent software may flag executor tools due to their injection-based nature. This is a false positive. You can whitelist the XCutors folder in your anticomponent settings to prevent interference.

### How do I update to the latest version?

XCutors includes a built-in auto-updater that checks for new releases. You can also manually download the latest version from the GitHub Releases page and replace the files.

### Can I add my own custom executors to XCutors?

Yes. The universal loader (xcutorsLoader) supports custom executor modules. Place your executor files in the designated plugins folder and configure the loader settings accordingly.

### Is script execution safe for my Roblox account?

Using any third-party executor tool carries inherent risks. XCutors is provided for educational and testing purposes. Users are responsible for their own accounts and should follow Roblox's Terms of Service.
